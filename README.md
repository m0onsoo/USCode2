# USCode2 ✌️

## Overview

Welcome to **USCode2** - a collaborative coding interview preparation repository designed to help our team master technical interviews for U.S. tech companies. This repository serves as our central hub for sharing solutions, discussing problem-solving strategies, and tracking our progress through coding challenges.

Our mission is to build a strong foundation in data structures, algorithms, and system design while fostering a supportive learning environment where we can grow together and achieve our career goals in the U.S. tech industry.

## 💻 Workflow & Rules

- Work on your own weekly branch using the format `<github-username>/week-NN`.
- Use the solution filename format `<problem-number>_<github-username>.py` (for example, `138_masibasi.py`).
- Push your solutions before the study session and merge them into `main` together during the session.
- Explain your solution process through comments in English.
- Include time and space complexity as comments at the top of each solution.

## Weekly Study Format

- **When:** Every Wednesday, 4:30 PM–6:00 PM
- **Homework:** Three problems, completed before the meeting
- **Live coding:** One problem, completed during the meeting
- **Difficulty:** Medium whenever possible

All four problems, including the live-coding problem, are published in advance. The live-coding interviewee solves only the three homework problems before the meeting and must not read the other members' live-problem solutions. The other two members solve all four problems and act as the interviewers/observers during the live session.

After reviewing everyone's approaches together, merge each member's branch into `main`.

## Problem Selection

- Select problems whose `Solved By` field is empty in the Notion problem database.
- Prefer Medium problems.
- Publish only the problem name, link, difficulty, and Homework/Live type; do not reveal topic hints.
- Rotate the live-coding interviewee each week.

## Repository Structure

```text
problems/
└── YYYY/
    └── week-NN/

        ├── 138_m0onsoo.py

```

Each weekly README contains the meeting date, roles, and four assigned problems.
