# Problems

Store weekly problem sets under `problems/YYYY/week-NN/`.

To start a new week:

1. Copy `templates/week/README.md` into the new weekly directory.
2. Select four unsolved Medium problems from the Notion problem database whenever possible.
3. Fill in the roles, meeting date, and problem list without adding topic hints.
4. Each member creates a branch such as `<github-username>/week-NN`.
5. Add solutions using `<problem-number>_<github-username>.py`.
6. Push before the meeting, then review and merge the branches together during the session.

Publish all four problems. The live-coding interviewee solves only the three homework problems in advance; the other two members solve all four.
